To run: python mdec_analysis.py --main --market all --workers 32

Make sure you have python, pandas, numpy and the last number is the number of cores your computer has. It runs about 45 mins on 1 core and 5 mins on 32.
One of the result files is too large to put on GitHub so you will have to run it to create it again.

Employment matching routinely requires applicants to reveal compensation expectations, scheduling constraints, workload preferences, mobility limits, and other sensitive information before either party knows whether a mutually acceptable opportunity exists. This study develops Selective Compatibility Signaling (SCS), a decision-support artifact that replaces direct preference revelation with compatibility signaling. SCS evaluates finite employer package menus against applicant constraints, applicant and employer utility, and qualification requirements, then releases a limited compatibility outcome while preserving the underlying preference structure. The artifact is instantiated across student employment, registered nursing, faculty hiring, and executive recruitment under five disclosure-and-commitment conditions. To make the multi-market experiment computationally feasible, the reported runs used 10% of the protocol market populations and began with 20-replication batches rather than a single 200-replication run. Student results show substantial gains in fill, placement, and false rejection but no privacy superiority. RN results support fill and placement noninferiority and lower false rejection, but not privacy superiority. Professor results show joint gains in matching, privacy, and false rejection. CEO results preserve matching while substantially reducing preference inferability. Together, the findings indicate that compatibility signaling can generate allocative, informational, or performance-preservation value depending on market complexity and constraint structure. The study contributes to DSS research by demonstrating that consequential decisions can be supported through selective information constraint, not only through expanded data collection or prediction.
